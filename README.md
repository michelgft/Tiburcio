## Sobre o Projeto

O Tiburcio é um sistema desenvolvido em Java para automatizar os processos principais de uma biblioteca, permitindo o controle de acervo, cadastro de usuários e gerenciamento completo de empréstimos e devoluções.

Este repositório foi criado para iniciar o versionamento do projeto. O código fonte e a documentação completa serão desenvolvidos ao longo da disciplina.

## Funcionalidades Principais
- Cadastro de itens (livros, revistas e outras mídias)
- Cadastro de usuários com diferentes categorias
- Controle de empréstimos e devoluções
- Cálculo automático de multas por atraso
- Consultas avançadas por título, autor, editora, etc.
- Histórico de empréstimos por usuário ou item
